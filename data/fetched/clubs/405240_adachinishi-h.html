部活動・生徒会

部活動

硬式野球

活動日・場所
火曜日ＯＦＦ・グラウンド＆人工芝スペース、土日祝日は他校へ遠征
活動内容
全体練習（攻撃メニュー、守備練習、実戦形式など）
自主練習（個別課題練習、ブルペン投球など）
追い込みトレーニング（曜日ごとにメニューを設定）
PR
「足立区から甲子園へ！」をモットーに日々白球を追っています！
目標は甲子園出場、目的は人間力向上です！

 

サッカー

活動日・場所
火・水・金・土（日）／グラウンド
活動内容
サッカー部は、「チームワーク・リスペクト」を大切に、全員サッカーで日々練習に取り組んでいます。都大会出場、Duoリーグ１部昇格が目標です。
PR
元気でやる気のある人、初心者から上級生まで歓迎します！

女子バレーボール

活動日・場所
火・水・木・土・日（大会及び練習試合等）　体育館
活動内容
元気に活動しています。〝最後まであきらめない″をモットーに、日々練習に励んでいます。経験者はもちろん、初心者の方でも気楽にバレーボールを楽しめること間違いなし！マネージャーも募集。
PR
少人数ですが、日々練習頑張っています！

男子バレーボール

活動日・場所
月・木・土　体育館
活動内容
私達は「バレーボールを楽しんで行う」ことをモットーに都内ベスト３２を目標に、先輩後輩分け隔てなく練習に励んでいます。
PR
未経験者からでもレギュラーになることもできます。青春を男子バレーボール部のみんなで過ごしませんか？

女子バスケットボール

活動日・場所
月・木・金・土　　・日（大会及び練習試合等）　体育館
活動内容
公式戦3回戦進出を目指して、日々明るく元気に活動をしています。部活動指導員の先生を迎え、新しい体制で和気あいあいと楽しく活動をしています。未経験者でも楽しく活動できます。
PR
先輩後輩が仲が良く、和気あいあいと練習を頑張っています。未経験者の部員もいます。私たちと一緒に高校生活を充実させましょう。

男子バスケットボール

活動日・場所
月・水・木・金・土・日
活動内容
東京都ベスト３２を目標に、一生懸命に練習に励んでいます。体育館練習は水・金・土です。日曜日は大会及び練習試合等を行うことがあります。
PR
やる気のある人、一生懸命にやれる人大募集！！

硬式テニス

活動日・場所
月・火・水・金・（土）・日
活動内容
各自が目標を設定し、日々練習に励んでいます。
ストロークやサーブなど、基本的な練習と試合形式の実戦練習を行っています。
PR
やりたい練習を取り入れることができます。

ソフトテニス

活動日・場所
月・水・木・金・土
活動内容
関東大会出場を目標に、日々練習に励んでいます。日曜日は大会及び練習試合等を行うことがあります。
PR
部員全員が目標高く、技術向上と人間力向上を目的に活動しています。高校生活で一緒にテニスしましょう！

バドミントン

活動日・場所
火・金・土・(日)曜日　　場所：本校，体育館
活動内容
高体連のバドミントン大会を目標に、基礎トレ・ステップワーク・筋トレ・フットワーク・基礎打ち・パターン練習・ノック練習・ゲーム練習などを、協力しながら活動しています。
PR
休まず週３日活動できる人が部員です。

陸上

活動日・場所
活動日：火・木・金曜日　　場所：本校，舎人陸上競技場
活動内容
種目毎にメニューを組んで、大会で自己ベストを目標に日々練習に励みます。現在は短距離・長距離・投擲（砲丸投げ、円盤投げ）毎でチームを組んでいます。
PR
初心者でも大歓迎です。先輩達と一緒に楽しく活動しましょう！

剣道

活動日・場所
月・火・金・土・（日）・剣道場
活動内容
「清く、誠実に、逞しく」をモットーに都大会出場、昇段を目標に練習に取組んでいます。基本練習を中心に稽古を行い、休日は練習試合や合同練習を行っています。
PR
人数は少ないですが、一人ひとり目標と課題をもって一生懸命に取り組んでいます。やる気があり、自分を変えたい方は入部お待ちしています。

柔道

活動日・場所
活動日：月・水・木・金曜日　　場所：柔道場
活動内容
安全に配慮しながら、心身を鍛え、強さのみでなく他人に対しての温かさやおもいやりの心を学ぶ。技術を高め、資格取得や大会で勝つことを目指す。
PR
本当の強さや友人、他人に対して温かい心を学ぶ。

水泳

活動日・場所
火・木・金
活動内容
四泳法に取り組むようにしています。初心者も歓迎しています。
PR
水泳は全身運動で、心肺機能も鍛えることができます。興味があれば、入部お待ちしています。

卓球

活動日・場所
活動日：木曜日　　場所：剣道場
活動内容
基礎練習からゲームまで。経験者はもちろん、初心者も大歓迎です。
PR
目標は楽しく活動すること。

吹奏楽

活動日・場所
月・火・木・金・土／３F音楽室
活動内容
コンクール・アンサンブルコンテストの大会出場、野球応援、合宿、他校との合同演奏、等　様々な活動・音楽を通じて人間的に成長することを目指しています。大会では金賞獲得が唯一の目標です。
PR
大会に出るからには結果を出すことが目標ですが、初心者も大歓迎。音楽を通じて、充実した高校生活を送りましょう！

軽音楽

活動日・場所
水：全員　　月火木金：バンド毎　　土・日：大会等の場合のみ
活動内容
部内でバンドを組んで活動しています。カヴァー曲の演奏はもちろんオリジナル曲を作り大会にも出場します。音響や照明なども部員が行います。創造性や企画運営力が身につく部活です。
PR
校内で最も部員数の多い部活ですが、仲良く切磋琢磨しています。卒業後も音楽を続けたり、エンタメ業界を目指す生徒も多数。

演劇

活動日・場所
火・木・金／多目的室
活動内容
普段は発声練習などの基礎練習をしています。大会参加に向けて、自分たちで脚本作成から、演技、演出、音楽、照明など、全て作り上げていきます。
PR
役者だけではなく、脚本が書いてみたい人や、音響、照明など舞台が好きな人はぜひ。他校の演劇部との交流もあります。

美術

活動日・場所
月・水・金／美術室
活動内容
普段は、個人のペースで活動しています。絵だけではなく、工芸制作もしています。
PR
描くことが好きな人、見ることが好きな人、美術に興味がある人はぜひ来てください。

漫画研究

活動日・場所
火・木/美術室
活動内容
・自由制作
・３ヶ月に１回部誌を制作（部員一人ひとりがイラストまたはマンガを制作しまとめて本にします）
PR
マンガやアニメの絵を描くことが好きな人達が集まって交流を深めることができる部活です。絵を描くことが苦手な人も大歓迎です。

ハンドメイキング

活動日・場所
火/調理室
活動内容
毎週、班ごとに協力して料理やお菓子作りをしています。調理が苦手でも、先輩が優しく教えてくれます。ひまわりプロジェクトというボランティア活動も行っています。文化祭ではクッキー販売を行います。
PR
調理内容の決定や買い出しなどは生徒が中心となって行います。
講師の先生による本格的な調理も行います！

茶道

活動日・場所
火／和室
活動内容
初心者でも講師の方がていねいに教えてくださるので大丈夫です。３年間続けると表千家の免状を取得することもできます。美味しいお茶とお菓子をいただくこともできます。
PR
厳しい雰囲気ではないので楽しくお稽古することができます。

伝統文化（かるた・和太鼓）

活動日・場所
月・水・木 

和室

活動内容
 主に実戦的な試合形式で日々練習を行っています。また百人一首の理解を深めたり決まり字の暗記、札の配置を考えるなど大会に向けて部員全員で一致団結して練習に励んでいます。

PR
百人一首かるたをやったことがある人もない人も、初心者・経験者を問わず大歓迎です！私たちと一緒に競技かるたを楽しみましょう！！

文芸同好会

活動日・場所

水／

活動内容

学期ごとに部誌「春望」を発行しています。東京都高等学校文化連盟文芸部門の行事に参加しています。

PR

令和8年度は7名で活動中。文章やイラストをかきたい人は気軽に来てください。
