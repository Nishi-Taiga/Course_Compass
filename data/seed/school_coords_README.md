# 学校の座標と最寄駅（school_coords.csv / school_nearest_station.csv）

くらべるシートの地図（2026-08-13 MTG決定）と、学校ごとの位置表示のために用意したデータ。

## school_coords.csv — 都立187校の緯度経度

| 列 | 内容 |
|---|---|
| `school_number` | `schools_master.csv` と同じ学校番号 |
| `name` / `ward` / `address` | `schools_master.csv` 由来 |
| `lat` / `lon` | 緯度・経度（WGS84） |
| `source` | `P29` = 国土数値情報 ／ `geocode` = 住所から変換 |

**出典（表示必須）**

> 「国土数値情報（学校データ）」（国土交通省）を加工して作成
> https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-P29-2023.html

2023年度版・**CC BY 4.0**（商用利用可・出典表記が必要）。都道府県別ダウンロードの
東京都（`P29-23_13_GML.zip`）から、学校分類コード `16004`（高等学校）かつ
管理者コード `2`（都道府県立）かつ名称が「東京都立」で始まるものを抽出＝**186校**。

残る **立川緑1校のみ** `source=geocode`。2023年度版の収録後に開校したため
P29 に存在せず、住所から座標を求めた。

## ⚠️ ジオコーディングについて

立川緑の座標取得に国土地理院の住所検索エンドポイント
（`msearch.gsi.go.jp/address-search/AddressSearch`）を使ったが、**これは国土地理院が
公式にAPIとして案内しているものではない**。地理院地図が内部で使っているエンドポイントで、
利用規約・頻度制限・クレジット要否のいずれも一次情報が確認できていない。

- **本番の実行時に呼び出してはいけない。** 座標は本CSVに固定値として持つ
- 新設校が増えて座標が必要になったら、まず**国土数値情報の新年度版**を確認する
- 検証として187校すべてをこの方法でも座標化し、P29 と突き合わせた結果、
  **ずれの中央値は62m**、186校中178校が300m以内で一致した（島しょ3校のみ1km超）

## school_nearest_station.csv — 最寄駅と徒歩分

`school_coords.csv` と `stations.csv`（647駅）から機械的に算出。再生成可能。

| 列 | 内容 |
|---|---|
| `station` | 直線距離が最短の駅 |
| `straight_km` | 学校と駅の直線距離 |
| `walk_min` | 徒歩の目安（分） |

徒歩分 = `直線距離 × 1.3 ÷ 80m/分` を切り上げ。1.3倍は道なり距離の近似、
80m/分は**不動産の表示に関する公正競争規約 施行規則**の基準。

**注意点**

- **徒歩20分超は26校**。うち本土19校は実際にバス通学が一般的（町田総合67分・
  八王子北54分・大泉桜31分など）。「徒歩◯分」とそのまま出さず、
  **バス利用が一般的である旨に置き換える**こと
- **島しょ部7校**（大島・大島海洋国際・新島・神津・三宅・八丈・小笠原）は鉄道が無く、
  この計算を適用してはいけない。最寄駅として本土の駅が出てしまう
- 直線距離ベースなので、川や線路で迂回が必要な場合は実際より短く出る

## 再生成

```
python3 scripts/build_school_coords.py     # P29 を取得して座標を作る
python3 scripts/build_nearest_station.py   # 最寄駅と徒歩分を計算する
```

# アクセス情報（school_access*.csv）

各校公式サイトの `https://www.metro.ed.jp/{slug}/access/access.html` から取得。
学校自身が書いた一次情報なので、系統名・乗り場番号・下車バス停まで載っている。

| ファイル | 内容 |
|---|---|
| `school_access_text.csv` | **原文**（1校1行）。画面に出すのはこれ |
| `school_access.csv` | 自動抽出（1校に複数行）。並べ替え・絞り込み用 |
| `school_access_verified.csv` | **徒歩20分超の9校を目視で確定させたもの。自動抽出より優先する** |
| `school_sites.csv` | 校名 → slug → アクセスページURL |

## 表示の原則

- **画面には原文をそのまま出す。** 系統名・乗り場番号を勝手に落とさない
- `ride_min` / `total_min` は並べ替えと絞り込みの内部処理にのみ使う
- **乗車分が空の学校は推定値を入れない。**「◯◯駅からバス・△△下車」までに留める

## 自動抽出の限界（2026-08-14 実測）

書式が学校ごとに大きく違うため、正規表現では取りきれない。
バス案内のある111校のうち、自動で乗車分が取れたのは41校。踏んだ落とし穴:

- 「所要時間約15分」「バスで約7分」「【一之江行き】5分」など**言い回しが統一されていない**
- 「バスで約7分（徒歩約15分）」の括弧内は**下車後の徒歩ではなく代替手段**。足すと誤り
- **「◯◯駅行き」は行き先であって乗車駅ではない。** 篠崎で乗車駅を取り違えていた
- 「永山駅」のように、**駅データベース上の名称（京王永山・小田急永山）と学校の書き方が違う**
- 大泉桜のように、交通案内がテキストとして存在しない学校がある（画像の可能性）

**全校を機械で構造化するならLLM抽出が要る。** ただし判定に効くのは
「駅から徒歩20分超」の9校だけなので、そこは目視で確定させてある。

## ODPTのバス時刻表について（2026-08-14 調査）

**この用途では使えない。** 対象9校を走るバス事業者の提供状況:

| 事業者 | 対象校 | ODPT |
|---|---|---|
| 都営バス | 篠崎 | ✅ **トークン無しで取得可**（`api-public.odpt.org`・CC BY 4.0） |
| 西東京バス | 八王子北 | ❌ 2025年6月末でAPI提供終了 |
| 京王バス | 調布北・永山 | ❌ 2025年6月末で終了 |
| 小田急バス | 総合工科・調布北 | ❌ 2025年9月末で終了 |
| 神奈川中央交通 | 山崎・町田総合 | △ チャレンジ限定ライセンス。`api-challenge.odpt.org` と専用トークンが要る |
| 立川バス | 拝島 | ❌ 事業者としてODPTに見当たらない |

乗車分が埋まらない **八王子北・山崎の2校**は、事業者サイトの時刻表を見て手で入れる。
2校なので仕組みを作るより速い。
